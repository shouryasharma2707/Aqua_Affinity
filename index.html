02 — The hard part

Rock, shadow, or wreck?

A boulder casts an acoustic shadow. So does a net drum. Naive detectors light up on both. We attack the ambiguity in three passes.

A

Despeckle, don't blur

Speckle in sonar is multiplicative, not Gaussian. A SRAD-style anisotropic pass flattens noise inside regions while clamping edges — so the shadow boundary that later fools lesser filters survives intact.

B

Shadow ↔ object geometry

Man-made bodies stand proud of the bed: their highlight and shadow lobes face opposite channels and their aspect ratio stays coherent across yaw. Ripple fields and ridge lines fail that consistency check.

C

Confidence, then veto

Every candidate gets a calibrated 0–100% score from backscatter contrast, shadow length and texture entropy — then a rule layer vetoes contacts that sit on gradient-shadow bands. False positives drop without touching recall.

03 — Under the hull

Five stages, one duty cycle

  1. 01

    Ingest

    XTF / SDF / tiled PNG log reader; ping headers parsed for lat, lon, range, altitude, towfish attitude.

  2. 02

    Condition

    Slant-range correction, TVG gain, despeckle, heave-aware row interpolation for dropouts.

  3. 03

    Detect

    Quantised YOLO-backbone head on 640 px tiles with 15% overlap; INT8 on ARM, FP16 on GPU.

  4. 04

    Score & veto

    Calibrated confidence + shadow-geometry rule layer strips shadow-band FPs.

  5. 05

    Report

    GeoJSON / CSV per contact: lat-lon, bounding dims, class, confidence, ping epoch.

The whole loop is a shared-library core with a thin web UI — the same binary that draws this console can sit on an AUV's companion computer, gated to < 8 W during a survey line.
